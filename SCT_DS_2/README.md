# SCT_DS_2 - Data Cleaning and Exploratory Data Analysis (EDA)

## Objective

Perform Data Cleaning and Exploratory Data Analysis (EDA) on the Titanic dataset to discover patterns, relationships, and insights. Analyze the effects of various features on passenger survival using visualizations and statistical summaries.

---

## Dataset

- **Dataset:** Titanic Dataset
- **Source:** Kaggle
- **Format:** CSV

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook
