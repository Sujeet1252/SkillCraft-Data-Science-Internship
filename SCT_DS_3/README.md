# SCT_DS_3 - Decision Tree Classifier

## Objective

Build a Decision Tree Classifier to predict whether a customer will purchase a product or service based on demographic and behavioral data using the Bank Marketing Dataset.

---

## Dataset

- **Dataset:** Bank Marketing Dataset
- **Source:** UCI Machine Learning Repository

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## Project Workflow

1. Import Libraries
2. Load Dataset
3. Data Cleaning
4. Exploratory Data Analysis (EDA)
5. Feature Encoding
6. Train-Test Split
7. Decision Tree Model Training
8. Model Evaluation
9. Feature Importance Visualization
10. Conclusion

---

## Evaluation Metrics

- Accuracy Score
- Confusion Matrix
- Classification Report
